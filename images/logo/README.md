# Logo

`logo.png` (174 x 71 px, transparante achtergrond, witte "Altena" + oranje
"auto's!") wordt automatisch gebruikt in header en footer.

Het bestand is klein; een grotere versie (min. ~300 px hoog) onder dezelfde
naam `logo.png` maakt het logo scherper op high-DPI schermen. De tekstvariant
(`.logo-fallback` in `css/style.css`) blijft als vangnet als het bestand ooit
ontbreekt.
